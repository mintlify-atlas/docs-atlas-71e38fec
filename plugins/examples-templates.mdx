The fastest way to build a Penpot plugin is to start from a working template and study real-world examples. This page collects every official starting point: a vanilla TypeScript starter kit, framework-specific templates, a growing library of focused code samples, and the `@penpot/plugin-styles` package that keeps your UI looking native to Penpot in both light and dark mode.

## Starter Templates

### Official Plugin Starter Template (Vanilla TypeScript)

The [penpot-plugin-starter-template](https://github.com/penpot/penpot-plugin-starter-template) is the recommended starting point for any new plugin. It ships with:

- A minimal `manifest.json` pre-configured for local development
- A `plugin.ts` entry point wired to the Penpot API
- Vite as the build tool with HMR during development
- TypeScript types from `@penpot/plugin-types`

```bash
# Clone and install
git clone https://github.com/penpot/penpot-plugin-starter-template my-plugin
cd my-plugin
npm install
npm run dev
```

After running `npm run dev`, open the Plugin Manager in your Penpot workspace and enter:

```text
http://localhost:4400/assets/manifest.json
```

<Tip>
  The starter template includes `@penpot/plugin-styles` out of the box. Import the CSS once and your plugin UI automatically inherits Penpot's colors, typography, and dark/light theme tokens.
</Tip>

## No-UI Plugin: Create Palette (Full Example)

Not every plugin needs a user interface. A plugin can run silently, do its work, and call `penpot.closePlugin()` when done. The **Create Palette** plugin — one of the plugins shipped with Penpot itself — is the canonical example.

You can install it right now by pasting this URL into the Plugin Manager:

```text
https://create-palette.plugins.penpot.app/assets/manifest.json
```

Its `manifest.json` is minimal — no `ui` field, just a code entry point and the permissions it needs:

```json
{
  "name": "Create Palette from library",
  "description": "Create a board with all the colors in the local library",
  "code": "/plugin.js",
  "icon": "/assets/icon.png",
  "permissions": ["content:read", "content:write", "library:read"]
}
```

And the entire `plugin.ts` reads the local color library and lays out a palette grid without ever opening a modal window:

```ts
main();

function main() {
  createPalette();
  penpot.closePlugin();
}

function createPalette() {
  // Read and sort colors from the local library
  const colors = penpot.library.local.colors.sort((a, b) =>
    a.name.toLowerCase() > b.name.toLowerCase() ? 1
    : a.name.toLowerCase() < b.name.toLowerCase() ? -1
    : 0
  );

  const cols = 4;
  const rows = Math.ceil(colors.length / cols);

  // Create a container board centered in the viewport
  const board = penpot.createBoard();
  board.name = 'Palette';
  board.x = penpot.viewport.center.x - (cols * 200) / 2;
  board.y = penpot.viewport.center.y - (rows * 100) / 2;
  board.resize(cols * 200 + (cols - 1) * 10 + 20, rows * 100 + (rows - 1) * 10 + 20);
  board.borderRadius = 8;

  // Add a grid layout
  const grid = board.addGridLayout();
  for (let i = 0; i < rows; i++) grid.addRow('flex', 1);
  for (let i = 0; i < cols; i++) grid.addColumn('flex', 1);
  grid.rowGap = 10;
  grid.columnGap = 10;

  // Place one color swatch per cell
  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      const color = colors[row * cols + col];
      if (!color) return;

      const swatch = penpot.createBoard();
      grid.appendChild(swatch, row + 1, col + 1);
      swatch.fills = [color.asFill()];

      const label = penpot.createText(color.name);
      label.fontWeight = 'bold';
      swatch.appendChild(label);
    }
  }
}
```

## @penpot/plugin-styles

The `@penpot/plugin-styles` package provides a ready-made CSS stylesheet that mirrors Penpot's own design system — colors, typography, form controls, buttons, and more — so your plugin UI feels native rather than foreign. It also handles dark/light theming automatically by adapting to the `data-theme` attribute that Penpot injects into the plugin iframe.

### Installation

```bash
npm install @penpot/plugin-styles
```

### Usage

Import the stylesheet once at the top of your CSS (or inside a framework entry file):

```css
@import '@penpot/plugin-styles/styles.css';
```

For framework projects, you can import it from JavaScript instead:

```ts
import '@penpot/plugin-styles/styles.css';
```

### What You Get

- **CSS custom properties** for all Penpot brand colors, mapped to dark and light values
- **Utility classes** for typography, spacing, and flex layouts consistent with the Penpot interface
- **Form element styles** — inputs, selects, checkboxes, toggles — styled to match the design panel
- **Automatic theming** — wrapping your markup in the container Penpot provides is enough; no JavaScript theme-detection code needed

```html
<!-- Example plugin panel using plugin-styles classes -->
<div class="plugin-panel">
  <h2 class="title-m">My Plugin</h2>
  <label class="label">Layer name</label>
  <input class="input" type="text" placeholder="Enter name…" />
  <button class="button button-primary">Apply</button>
</div>
```

<Tip>
  The `@penpot/plugin-styles` library is not required, but it is strongly recommended. Without it you will need to implement your own dark/light color switching and risk your plugin looking out of place in the Penpot UI.
</Tip>

For a live demo of every available component, visit the [Penpot Plugin Styles documentation](https://styles-doc.plugins.penpot.app).

For icons, Penpot's own UI uses **Feather Icons** — using the same set in your plugin keeps the visual language consistent. Browse available icons at [feathericons.com](https://feathericons.com).
