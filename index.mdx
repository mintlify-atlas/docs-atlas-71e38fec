Penpot is the open-source design and prototyping platform built for teams that need real ownership of their design infrastructure. Whether you run it in the cloud or deploy it on your own servers, Penpot works with open standards — SVG, CSS, HTML, and JSON — so design and code stay in sync from day one.

## Build on Penpot

<Steps>
  <Step title="Choose your deployment">
    Use Penpot on the [cloud](https://design.penpot.app) for free, or [self-host with Docker](/self-hosting/docker) for full control of your design infrastructure.
  </Step>
  <Step title="Set up integrations">
    Connect Penpot to your existing toolchain using [webhooks](/integrations/webhooks) and [access tokens](/integrations/access-tokens) to trigger CI/CD pipelines, sync assets, or notify Slack.
  </Step>
  <Step title="Extend with plugins">
    Use the [Plugin API](/plugins/overview) to build custom tools — asset importers, brand checkers, code generators, and more — directly inside the Penpot workspace.
  </Step>
  <Step title="Enable AI workflows">
    Connect an AI agent via the [MCP server](/integrations/mcp-server) to automate design tasks, generate variants, extract layout metadata, and sync design tokens to code.
  </Step>
</Steps>
