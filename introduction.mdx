Penpot is the open-source design platform for teams that build digital products at scale. Unlike proprietary design tools, Penpot is built on open web standards — SVG, CSS, HTML, and JSON — meaning designs are always readable by developers and AI systems alike. Whether you choose the hosted cloud version at [design.penpot.app](https://design.penpot.app) or deploy it on your own infrastructure, the experience is identical and you retain complete ownership of your design data.

## Why Penpot

Penpot's core strength is giving teams **full ownership of their design infrastructure**. It was built from the ground up to be self-hostable, to work with open standards, and to close the gap between design and engineering. Here are the key differentiators:

## Cloud vs. Self-Hosted

Penpot is **deployment agnostic**. You can start immediately on the cloud or run it entirely on your own servers.

<Tabs>
  <Tab title="Penpot Cloud">
    The fastest way to get started. No setup required — just sign up and start designing.

    - Hosted at [design.penpot.app](https://design.penpot.app)
    - Always on the latest version
    - Managed infrastructure, backups, and SSL
    - Free tier available; Enterprise plan for larger organizations
  </Tab>
  <Tab title="Self-Hosted">
    Full control over your environment. Ideal for organizations with strict data governance or compliance requirements.

    - Deploy with Docker Compose, Kubernetes (Helm), or Elestio
    - Control your own upgrade cadence
    - Integrate with your internal identity provider (LDAP, OIDC, SSO)
    - Docker images are published shortly after cloud updates
  </Tab>
</Tabs>

## Core Capabilities

### Design Systems: Tokens, Components & Variants

Penpot brings design systems to code-minded teams with native [Design Tokens](https://penpot.dev/collaboration/design-tokens), reusable Components, and Variants — all forming a single source of truth for UI consistency across projects and platforms.

### CSS Grid and Flex Layout

With [CSS Grid and Flex Layout](https://help.penpot.app/user-guide/designing/flexible-layouts/) support, teams design responsive interfaces that behave like real production code from day one. No guessing, no translation layer.

### Inspect Mode

The Inspect tab provides developers with instant access to SVG, CSS, and HTML code derived directly from the design. Ready-to-use code is always one click away.

### Integrations & API

Penpot offers [webhook support and an API](https://penpot.app/integrations-api) accessible via access tokens, making it easy to integrate into CI/CD pipelines, design ops workflows, and third-party tooling.

## Penpot Enterprise

[Penpot Enterprise](https://help.penpot.app/user-guide/account-teams/enterprise-plan/) is the paid plan for organizations that need to scale design work across multiple teams with advanced governance and security controls. Enterprise features include:

- **Admin Console** — centralized team and user management
- **SSO / Identity Provider integration** — connect your existing IdP via OIDC, SAML, or LDAP
- **Advanced permissions** — fine-grained access control across teams and projects
- Available for both cloud and self-hosted deployments
